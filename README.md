🎮 Dodge the Blocks – ARM DE1-SoC Mini Game

A fast-paced mini-game developed in C for the ARM Cortex-A9 processor on the DE1-SoC development board. 

🕹️ Game Overview: 

 ➡️In Dodge the Blocks, players control a character that must avoid falling blocks descending from the top of the screen. The game challenges players' reflexes and timing as the speed and frequency of the blocks  increase over time.​

🛠️ Technologies Used

 ➡️Programming Language: C​

 ➡️Hardware Platform: DE1-SoC Development Board with ARM Cortex-A9​

 ➡️Display Output: VGA Monitor​

 ➡️Input Device: PS/2 Keyboard​

 ➡️Development Tools: Quartus Prime, ARM DS-5​
